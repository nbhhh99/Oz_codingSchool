# 8일차 Docker 실행화면

`app/Dockerfile`, `app/.dockerignore`를 작성하고, FastAPI 앱을 Docker 이미지로 빌드 및 컨테이너로 실행한 결과입니다.

## 1. .dockerignore / Dockerfile 작성

- `app/Dockerfile` : `python:3.13-slim` 베이스 이미지에 `uv`를 설치하고, `uv sync`로 의존성을 설치한 뒤 `fastapi run app/main.py`로 앱을 실행하도록 구성했습니다.
- `app/.dockerignore` : `.env`, 파이썬 캐시(`__pycache__`, `*.pyc`), 라이브러리 캐시(`.mypy_cache`, `.pytest_cache` 등), `docker-compose.yml`, `docs/`, `README.md`, IDE 설정 파일(`.vscode/`, `.idea/`) 등 이미지에 포함될 필요 없는 파일을 제외했습니다.

## 2. 이미지 빌드

`docker build -f app/Dockerfile -t ai-health-app .` 명령으로 이미지 빌드가 정상적으로 완료되었습니다.

![](./images/docker%20build%20성공%20로그.png)

## 3. 컨테이너 실행

`docker run --rm -p 8000:8000 --env-file .env -e DB_HOST=host.docker.internal ai-health-app` 명령으로 컨테이너를 실행하면, Uvicorn 서버가 정상적으로 기동되고 요청을 처리하는 것을 확인할 수 있습니다.

![](./images/docker%20run%20컨테이너%20실행%20로그.png)

## 4. 브라우저 접속 확인

컨테이너로 띄운 서버에 브라우저로 `http://localhost:8000` 접속 시, 로컬에서 직접 실행했을 때와 동일하게 앱이 정상 동작하는 것을 확인했습니다.

![](./images/브라우저%20화면.png)
