# 7일차 앱 실행화면

FastAPI 앱(`uv run fastapi run app/main.py`)을 실행한 뒤, 프론트엔드에서 각 endpoint가 어떻게 동작하는지 캡처한 화면입니다.

## 회원가입 / 로그인 플로우

- `POST /api/v1/auth/signup` — 회원가입
- `POST /api/v1/auth/login` — 로그인
- 가입 직후 `role`은 `PENDING`으로 생성되며, 관리자 승인 전까지는 대기 화면이 노출됩니다.
