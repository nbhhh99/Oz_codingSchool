# 7일차 앱 실행화면

FastAPI 앱(`uv run fastapi run app/main.py`)을 실행한 뒤, 프론트엔드 화면에서 각 endpoint가 실제로 어떻게 동작하는지 확인하고 캡처한 화면입니다.

## 1. 회원가입 / 로그인 플로우

- `POST /api/v1/auth/signup` — 회원가입 폼에 이름, 이메일, 비밀번호, 전화번호 등 정보를 입력하고 제출하면 회원가입이 처리되고, 성공 시 완료 안내와 함께 계정이 생성됩니다.
- `POST /api/v1/auth/login` — 가입한 이메일/비밀번호로 로그인하면 토큰이 발급되고 로그인 상태로 전환됩니다.
- 가입 직후 계정의 `role`은 `PENDING`으로 생성되며, 관리자가 승인하기 전까지는 서비스 이용이 제한된 대기 화면이 프론트에 노출됩니다.

## 2. 회원 관리 (관리자 승인) / 환자 등록

- `GET /api/v1/users` (관리자 전용) — 관리자 계정으로 로그인하면 승인 대기 중인 회원 목록을 조회할 수 있고, 화면에서 유저의 role을 STAFF/ADMIN 등으로 변경(승인)할 수 있습니다.
- `POST /patients` — 승인된 계정으로 로그인 후 환자 등록 폼에 환자 정보를 입력하면 새 환자가 시스템에 등록되고, 환자 목록 화면에 반영됩니다.

## 3. 진료 기록 등록 및 X-Ray 업로드

- `POST /patients/{patientId}/medical-records` — 등록된 환자를 선택해 진료 기록 등록 폼에서 증상을 입력하고 X-Ray 이미지를 업로드하면, 해당 환자의 진료 기록으로 저장됩니다.
- `GET /patients/{patientId}/medical-records/{recordId}` — 환자 상세 화면에서 등록된 진료 기록 목록을 확인하고, 개별 기록을 클릭하면 업로드한 X-Ray 이미지와 증상 정보가 상세 화면에 표시됩니다.

## 4. AI 폐렴 예측

- `POST /patients/{patientId}/medical-records/{recordId}/ai-prediction` — 진료 기록 상세 화면에서 AI 예측 버튼을 실행하면, 업로드된 X-Ray 이미지를 SimpleCNN 모델에 입력해 폐렴 여부를 분석합니다.
- 결과 화면에는 예측 결과(Positive/Negative)와 신뢰도(Confidence), 사용된 모델명이 함께 표시됩니다.
